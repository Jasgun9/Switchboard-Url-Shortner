Reference

API

A small JSON API over the same data as the dashboard, versioned under /api/v1/. Everything the web interface can do, a script can do.

Authentication

Send an API key as a bearer token. Keys are scoped to the account that created them, so a request can only ever read or write that account's links. Keys cannot create further keys — that needs a signed-in session.

Shell 
curl -X POST {{ web_domain }}/api/v1/urls/ \
  -H "Authorization: Bearer usk_1a2b3c4d_<secret>" \
  -H "Content-Type: application/json" \
  -d '{"destination": "https://example.com/a/long/url", "alias": "portfolio"}'

Endpoints

POST
/api/v1/urls/

Create a short link. Works without credentials at a lower rate limit; an anonymous link has no owner and cannot be edited later.

GET
/api/v1/urls/

List your links. Accepts search, status (active, expired, disabled), ordering, page and page_size.

GET
/api/v1/urls/{id}/

Retrieve one of your links.

PATCH
/api/v1/urls/{id}/

Update destination, title, expires_at, password or is_active. The short code itself cannot change.

DELETE
/api/v1/urls/{id}/

Delete a link. It stops redirecting immediately and its click history is kept, but the code is released and can be claimed again.

GET
/api/v1/urls/{id}/analytics/

Click analytics for one link. Accepts ?days=1..365, default 30.

GET
/api/v1/api-keys/

List your API keys. Session authentication only.

POST
/api/v1/api-keys/

Create a key. The secret is returned once, in the token field.

DELETE
/api/v1/api-keys/{id}/

Revoke a key. The row is kept so the audit trail survives.

GET
/api/v1/qr/{code}.png

QR code for a short link, as a PNG. Public, since it only encodes the already-public short URL.

Errors

Every failure uses the same envelope. Validation failures add a details object keyed by field.

409 Conflict
{
  "error": {
    "code": "ALIAS_ALREADY_EXISTS",
    "message": "The requested alias is already in use."
  }
}
CodeHTTPMeaning
VALIDATION_ERROR400One or more fields were rejected; see error.details.
ALIAS_ALREADY_EXISTS409Another link already claims that custom alias.
AUTHENTICATION_REQUIRED401No credentials were supplied.
AUTHENTICATION_FAILED401The API key is invalid, revoked or expired.
NOT_FOUND404No such resource — or it belongs to someone else.
RATE_LIMITED429Too many requests; wait for Retry-After seconds.
CODE_GENERATION_FAILED503Could not allocate a free short code. Retry.

Rate limits

Limits are counted per account for authenticated requests and per IP otherwise. Exceeding one returns 429 with a Retry-After header giving the seconds to wait.
