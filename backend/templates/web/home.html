What every link gets

The same capabilities apply whether a link is created here, from the dashboard, or through the API.

Click analytics

Countries, devices, browsers, operating systems and referrers, recorded on every visit.

QR code

A PNG generated on demand for every short link, ready to download and place anywhere.

Expiry

Set a moment after which the link stops redirecting. Useful for campaigns and time-boxed access.

Password protection

Gate the destination behind a password. Attempts are rate limited and never stored in the clear.

REST API

Create and manage links from scripts with a scoped API key. Everything the dashboard does.

Custom aliases

Claim a readable path instead of a generated code, with reserved names kept out of reach.

Developer API

From the command line

Issue a scoped key and create links from a deploy pipeline, a script, or your terminal. Responses are plain JSON with a consistent error envelope.

Read the API reference

Shell 
curl -X POST {{ web_domain }}/api/v1/urls/ \
  -H "Authorization: Bearer $SHORT_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destination":"https://example.com"}'
